# Geetha Typewriting Institute Website

A modern, responsive website developed for Geetha Typewriting Institute to showcase its courses, facilities, gallery, and contact information.

## 🌐 Live Website

**[Visit the Live Website](https://geetha-typewriting-institute-es5gpov4a-meenatchi1.vercel.app/)**

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Institute information and course details
- Image gallery and visual presentation
- Easy navigation and user-friendly interface
- Contact information for prospective students

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- TypeScript
- Vite

## 🎯 Project Objective

To establish a professional online presence for Geetha Typewriting Institute and make institute information easily accessible to prospective students.

## 🚀 Deployment

The website is deployed using Vercel.
